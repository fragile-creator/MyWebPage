## 1. 관심 분야 및 관심 계기

### 📌 관심 분야
- **개인 웹을 혼자서 만들기**
- 예전부터 배운 점을 저장하고 리마인드 하기 위한 개인 웹을 만들고 싶었습니다.

### 💡 관심을 갖게 된 계기
- 전부터 개인 웹을 제작하고 싶었으나, 어떻게 시작할지 생각하기 어렵고 접근하기 어려웠습니다.
- 그러나 2026년 기준, 인공지능의 발전으로 웹 개발에 대한 접근성이 매우 좋아져 이참에 AI의 도움을 받아 웹을 만들되, 단순히 AI에게 맡기는게 아닌, 내가 무엇을 원하는지, 어디서 막혔는지 확실히 알고, 문제가 해결된 이유에 대해 깊이 고민하는 능동적 개발을 기대하고 개발을 시작합니다.

## 2. 학습 목표 및 다음 실행 계획

### 🎯 단기 및 중기 학습 목표
1. **HTML / CSS / TypeScript 기본기 완성**: 기본 문법 숙지, 만들어진 파일을 읽고 어떤 기능을 하는지 이해력 생성 및 능동적으로 수정할 수 있는 역량 확보.
2. **웹 접근성 및 표준 준수**: 스크린 리더와 키보드만으로도 원활하게 탐색할 수 있는 접근성 높은 마크업 작성 역량 확보.
3. **모던 프론트엔드 프레임워크 학습**: 정적 웹 기초를 다진 후, React 또는 Vue.js 기반의 컴포넌트 주도 개발 방식 습득.

### 🚀 다음 실행 계획
- 이번 과제 배포를 성공적으로 완료한 후, 템플릿을 받고 수정하는 대신, 백지에서부터 웹 구축 도전.
- 다음 개인 프로젝트로 로컬 스토리지를 활용한 대화형 웹 유틸리티(예: 마크다운 실시간 미리보기 도구)를 기획하고 GitHub Pages로 배포해 볼 계획.

## 3. 보유 기술 및 활용 사례

| 기술 스택 | 숙련도 | 실제 활용 사례 |
|:---|:---:|:---|
| **Git / GitHub** | 기본 활용 | 버전 관리, 브랜치 기반 작업, 커밋 메시지 규칙 준수, 저장소 관리 |
| **GitHub Actions** | 기본 활용 | GitHub Pages 워크플로(`.github/workflows/hugo-pages.yml`)를 통한 CI/CD 배포 자동화 |
| **Hugo (SSG)** | 기본 활용 | Hugo 디렉터리 구조(`config`, `content`, `static`, `assets`, `themes`) 이해 및 TOML 설정 커스터마이징 |
| **HTML / CSS** | 기본 활용 | 데스크톱 본문 중앙 정렬(`margin: auto`), 헤더 간격 조정, 마크다운 기반 구조화된 문서 마크업 |
| **C / C++** | 기본 활용 | 전공 기초 프로그래밍, 자료구조 및 알고리즘 구현 실습, 콘솔 기반 응용 프로그램 작성 |
| **Linux (CLI)** | 기본 활용 | 쉘(Bash) 기본 명령어 조작, 파일 시스템 탐색 및 권한 관리, Git 환경 실습 |
